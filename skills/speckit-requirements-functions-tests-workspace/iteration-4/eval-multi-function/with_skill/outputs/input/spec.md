# Feature Specification: 注文登録と取消（架空の検証用仕様）

## 概要

この資料はスキル検証用の架空仕様であり、実在する業務の承認済み要件ではない。
登録と取消を別々の業務機能とし、監査記録は両方に共通する。

## Functional Requirements

- **FR-001**: 注文担当者は商品 A の数量を整数 1 件以上 5 件以下で登録できる。登録前に対象注文が存在しないこと。数量 1 と 5 は状態「受付済み」で 1 注文として保存する。数量 0 と 6 は「数量は1～5で入力してください」と表示し、注文を保存しない。
- **FR-002**: 注文担当者は状態「受付済み」の注文を取り消せる。取消後の状態は「取消済み」となる。同じ注文に再度取消を実行した場合は「既に取消済みです」と表示し、状態を変更しない。
- **FR-003**: 登録成功時と取消成功時に、注文 ID と操作種別（登録または取消）を持つ監査記録をそれぞれ 1 件作成する。拒否された登録・再取消では監査記録を増やさない。同じ注文の登録後に取消を行うと、その注文 ID の監査記録は登録 1 件・取消 1 件の合計 2 件になる。

## Assumptions

- テスト環境には注文担当者としてログイン済みで、商品 A を使用する。各テストは注文と監査記録を空に戻してから開始する。保存内容と監査記録を確認できる検証用の参照手段が利用できる。
- 正常登録の注文 ID はテスト環境が発行した値を記録し、取消と監査の確認に使う。ID の形式はこの仕様の検証対象外とする。

## Out of Scope

- 在庫、決済、認証方式、性能測定、テスト実行結果は扱わない。
