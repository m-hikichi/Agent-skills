## 修正範囲

- 入力が同じ場合、既存JSONの機能分割、追加テスト、リンク、レビュー判断を保持する。
- 入力変更とレビュー修正が重なる場合は上書きを止め、別名の更新案を作る。自動マージはしない。
- 複数機能にまたがる結合テストを許可し、無関係な要件・機能リンクを拒否する。
- テスト具体化の表示と公開判定を共通化し、レビュー根拠・ID登録の不足も検査する。
- 古いreportキャッシュを表示・公開判定に使わず、現在のJSONから再評価する。
