# サイズ設定復旧の修正・検証（2026-10-17）

## 結果

サイズ値だけが壊れた場合に、読み取れる位置と選択ペットを保持するよう元アプリを修正した。
元プロジェクトの変更ファイルはAppSettings.csとSettingsServiceTests.csの2ファイル。
仕様・画像・利用者のsettings.jsonは今回変更していない。

ScalePercent専用のJSON変換処理を追加した。文字列、真偽値、配列、オブジェクト、小数、
int範囲外の値はサイズの既定値へ戻す。他のプロパティの読み込みを継続する。
JSON構文全体の破損、未知の将来スキーマの扱いは従来のまま。
