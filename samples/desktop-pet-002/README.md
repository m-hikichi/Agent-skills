## 実案件で新しく見つかったスキルの問題

初回自動生成は、原文に20件ある受入条件を3件しか抽出せず、その3件も改行後のThenを落としていました。
それにもかかわらずdraftの構造検査は通りました。
今回の実案件検証により、「抽出済み項目の紐づけ検査」だけでは「入力からの抽出漏れ」を検出できないことが判明しました。

[automatic](automatic/) に初回出力を保存し、[build_documents.py](build_documents.py) で
原文から20件を復元・親子関係を補完してレビュー用資料を再構成しました。
このスクリプトは本案件専用の補完です。その後の不具合修正（2026-09-27）で、スキル本体の
受入条件抽出を修正しました。太字のThenを節の終了と誤認せず、項目の継続行をまとめて抽出します。
[修正後の自動生成](automatic-fixed/) では、手動補完なしで20件すべてと、その事前条件・操作・期待結果を
抽出できることを確認しました。修正前のautomaticと補完済みreview-draftは比較用に保持しています。
回帰テストは20件（4/7/9）の複数行条件、見出し・太字・日本語マーカー、次節・コード例の除外を検証します。
独立コードレビューの追加指摘（実見出し後のNotes混入、入れ子箇条書きの誤分割）も修正し、
再レビューの4パターンと全96件の単体テストが成功しました。新規の自動抽出20件は、補完済み資料と
本文・親ストーリー・原文開始位置がすべて一致しています。スキル形式の検証も成功しました。
これは抽出コードのレビューであり、review-draft全体の最終意味レビューの代わりではありません。
抽出件数・原文との照合を別に検査する仕組みも必要です。
