# 短時間の画面動作確認（2026-10-17）

利用者の指示により、8時間の連続稼働は今回実施せず、後日に延期した。

## 実施方法

元アプリと同じPetWindow・ネイティブウィンドウ処理を、検証用のAvaloniaアプリから起動した。
Windowsの実ウィンドウとUIイベントループを使用し、2ペット×4サイズを順に切り替えた。
各組合せで約1.2秒、アニメーションのコマ番号と位置を観測した。
検証後はウィンドウとプロセスを終了しており、8時間動かし続ける処理はない。

普段の設定を保護するため、元のAppの起動処理・常駐メニュー・設定保存処理は使わず、
位置保存コールバックは何も保存しないものに置き換えた。マウス操作の注入やOS設定の変更は行っていない。
したがって、これは実際の画面コンポーネントの動作確認であり、アプリの通常起動から終了までの一連の合格ではない。
