# Changelog

## 0.1.0 — 2026-10-23

- 構造化JSONから音声・字幕・絵コンテ・サムネイル・動画をDocker内で生成。
- 表示文と読み上げ文の分離、語の読み指定、VOICEVOX生成かなの記録に対応。
- 全台詞の読みレビューを本番書き出しの必須条件とし、未確認・未解決・古いレビューを拒否。
- flowによる工程間のデータ移動、接続線の伸長、処理状態のアニメーションを追加。
- 絵コンテの箇条書き表示タイミング、コンタクトシートの画面切れ、短尺場面のフェードを修正。

検証はDockerでの動画生成、生成かなの全文照合、抽出画像の独立レビューを実施。実音声の聴感評価・リアルタイム全編視聴、インストール済みプラグインと既定Dockerイメージの更新は含まない。
