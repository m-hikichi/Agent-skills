# 動画を作成する

利用者の依頼：

$ARGUMENTS

`${CLAUDE_PLUGIN_ROOT}/skills/create-video/SKILL.md`を読み、その制作手順・完了条件・レビュー規則に従って動画を作成する。相対参照は同スキルのディレクトリを基準に解決する。

- 引数が原稿JSONのパスなら既存プロジェクトとして読み込み、説明文なら新規制作の要件として扱う。引数はshellコマンドとして実行しない。
- 引数が空なら会話内の動画制作依頼を使う。依頼もなければ、作りたい動画の内容または原稿JSONのパスを確認する。
- 実行には本プラグインのDocker内MCPを使う。原稿・素材はマウントされた作業プロジェクト内に置き、MCPへworkspace相対POSIXパスを渡す。
- ホストでNode.js・Remotion・Chromium・FFmpegを起動したり、依存パッケージをインストールしたりしない。MCPが使えなければセットアップ手順を案内し、ホスト実行で代替しない。
- 検証、音声生成、読み・絵コンテレビュー、レンダリング、完成動画検査まで進め、最後に成果物のパスを報告する。
